# LexRAG: A Retrieval-Augmented Legal AI Assistant for Vietnamese Law

LexRAG is an AI-powered legal question answering system designed for Vietnamese legal documents. Built on the Zalo AI Challenge (ZAC) 2021 dataset, the project leverages a Retrieval-Augmented Generation (RAG) architecture to retrieve relevant legal references and generate accurate, context-aware responses using Large Language Models (LLMs). The entire system is packaged as a production-ready FastAPI application.

## Features

* Retrieval-Augmented Generation (RAG) pipeline for legal question answering
* Semantic document retrieval using vector embeddings
* LLM-powered answer generation
* FastAPI backend with RESTful API support
* Interactive web-based chat interface
* Automatic dataset indexing and vector store creation on first launch

## Setup & Installation

### 1. Install Dependencies

Open a terminal and install the required packages:

```bash
pip install -r requirements.txt
```

### 2. Configure Environment Variables

Create a `.env` file in the project root directory and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

### 3. Run the Application

Start the FastAPI server:

```bash
uvicorn api:app --reload
```

On the first launch, the system will automatically download the dataset, generate embeddings, and build the vector index.

### 4. Access the Application

* **Web Chat Interface:** `http://127.0.0.1:8000`
* **API Documentation (Swagger UI):** `http://127.0.0.1:8000/docs`

## Technology Stack

* FastAPI
* Groq API
* Retrieval-Augmented Generation (RAG)
* Vector Embeddings
* ChromaDB / FAISS (depending on configuration)
* Python

## Dataset

This project utilizes the Vietnamese legal dataset released as part of the Zalo AI Challenge (ZAC) 2021.
